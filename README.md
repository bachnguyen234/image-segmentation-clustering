# Image Segmentation Clustering

This project explores **unsupervised machine learning for image analysis** by clustering image segments based on their visual characteristics.

The analysis examines whether image segments can be grouped into meaningful clusters without relying entirely on predefined labels.

## Analysis

The project includes:

- Loading and preprocessing image segment data
- Representing image segments as numerical features
- Applying unsupervised clustering methods
- Comparing discovered clusters with available labels
- Visualizing clustering results
- Evaluating patterns and limitations in the resulting groups

## Methods

**Image Processing**
- Image segmentation
- Feature extraction
- Image-based exploratory analysis

**Machine Learning**
- Unsupervised clustering
- Cluster evaluation
